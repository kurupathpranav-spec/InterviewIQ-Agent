API Routes
MethodEndpointDescriptionAI
GET / Serves SPA shell (index.html via Jinja2) —
GET /api/health Service health check – returns model ID & status —
POST /api/analyze-resume Accepts form-data (text + optional PDF). Returns skills, strengths, scores RAG Granite
POST /api/generate-questions Generates 10 interview questions (technical / behavioral / situational) RAG Granite
POST /api/evaluate-answer Scores a Q&A pair 0–10. Returns grade, feedback, follow-up Granite
POST /api/generate-report Produces full report: skill gap table, 6-week plan, hire recommendation Granite

🤖 Agentic IBM Granite Calls (per session)

Call 1 – Resume Analysis
Input: resume text + RAG context → JSON: skills, readiness score, gaps, topics
Call 2 – Question Generation
Input: role + experience + skills + RAG → JSON: 10 questions across 3 types
Calls 3–12 – Per-Answer Evaluation
Input: question + answer → JSON: score/10, grade, strengths, improvements, follow-up
Call 13 – Final Report Generation
Input: all scores + role → JSON: report, skill gap table, 6-week plan, resources
